# ПАСПОРТ ПРОЕКТА (PROJECT PASSPORT)

## 📌 Основная информация
- **Название проекта:** Job Hunter CRM
- **Статус:** MVP (Минимально жизнеспособный продукт)
- **Тип:** Локальное десктоп-приложение (Web UI + Local Backend)
- **Основная философия:** Zero-dependency, Local-first, Anti-BS.

## 🎯 Проблема и Решение
**Проблема:** Рутинный поиск работы требует ручного копипаста на десятках разных площадок (HH.ru, LinkedIn, Хабр Карьера, RemoteOK), написания уникальных сопроводительных писем под каждую вакансию и борьбы с "мусорными" предложениями от HR.  
**Решение:** Автономная CRM, которая агрегирует вакансии, отсеивает мусор с помощью фильтров, автоматически подбирает нужную персону (роль) кандидата, генерирует идеальное сопроводительное письмо через ИИ и в один клик заполняет формы откликов прямо в браузере пользователя, обходя защиты от ботов.

## 🛠 Технологический стек
- **Backend:** Python 3.x (стандартные библиотеки `http.server`, `sqlite3`, `urllib`).
- **Frontend:** Single-file Vanilla JS, Tailwind CSS (через CDN).
- **База данных:** SQLite (`jobs.db`).
- **AI Engine:** Google Gemini API (`gemini-1.5-flash`).
- **Автоматизация:** JS Bookmarklet (умная закладка для инъекции данных в DOM).

## 🚀 Ключевые фичи (Core Features)
1. **Multi-Scraper:** Сбор вакансий из Telegram, HH.ru API, RemoteOK.
2. **Anti-BS Фильтр:** Автоматический поиск красных флагов (тестовые задания до собеса, обязательное ИП/Самозанятость).
3. **Multi-Persona Profiles:** Динамическое переключение профилей кандидата (Frontend / Fullstack / Product) и языков (RU/EN) под конкретную вакансию.
4. **AI Match & Pitch:** Расчет вероятности мэтча (Scoring 0-100%) и генерация персонализированного Cover Letter + Short DM.
5. **PDF Parser:** Локальное извлечение текста из PDF/Docx и умный маппинг в профиль через LLM.
6. **Stealth Auto-Apply:** Вставка сгенерированных откликов прямо на целевых сайтах через Bookmarklet (обход Cloudflare / DataDome).

## 📋 Ограничения и Требования
- Требуется VPN для работы Gemini API (из РФ).
- Система должна запускаться через `start.sh` для предотвращения конфликтов портов.
- Запрещено использование тяжелых фреймворков (React, Vue, Django) без утвержденного ADR.
